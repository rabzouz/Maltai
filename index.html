Outils natifs

Un agent qui sait agir dans ton workspace

Les briques importantes d'un agent moderne, intégrées nativement dans ton instance auto-hébergée.

Browser

Navigation web, extraction de texte, liens, formulaires, clics Playwright et captures PNG en direct.

Fichiers

Lecture, écriture, patch, PDF, Word, Excel, ZIP et téléchargement dans un workspace isolé par utilisateur.

Terminal admin

Console, processus longs, logs, kill, version app et inspection Git read-only pour les administrateurs.

Brain

Mémoire vectorielle, recherche sémantique, souvenirs épinglés et nettoyage contrôlé du contexte.

Ollama

Liste, téléchargement avec progression et suppression des modèles locaux directement depuis l'interface.

Crédits

Plans Basic, Premium, Admin, suivi des tokens et balance pour cadrer l'usage des outils et modèles.

Cas d'usage

Pour administrer, chercher, coder et automatiser

Tout depuis le même endroit, sans jongler entre dix outils différents.

Recherche web

Lis des pages, extrais les liens, capture une page et produis une synthèse structurée. L'agent navigue pour toi.

IA locale

Installe des modèles Ollama depuis l'interface et bascule entre plusieurs providers selon la tâche et la confidentialité.

Workspace

Lis, crée ou patches des fichiers dans un espace isolé par utilisateur. Exporte en PDF, JSON ou CSV.

Administration

Surveille la version, les processus, les logs, les crédits et les accès. Console admin intégrée.

Sécurité

Des garde-fous pour ouvrir les outils sans perdre le contrôle

Maltai est conçu pour être partagé en toute confiance, même en production.

Rôles

Basic, Premium et Admin séparent le chat, les outils agent et les commandes sensibles.

Isolation

Sessions et workspace isolés par utilisateur. Chaque compte ne voit que ses propres données.

Anti-SSRF

Les outils web bloquent les adresses internes, y compris au fil des redirections.

Admin only

Terminal, Python admin, processus et Git read-only restent réservés aux administrateurs.

Installation

Prêt en quelques commandes

Clone, installe et lance. Docker, Coolify ou manuel — tu choisis.

bash — Maltai v1.1.1
$git clone https://github.com/rabzouz/Maltai.git
$cd Maltai
$python3 -m venv venv && source venv/bin/activate
$pip install -r requirements.txt
$python app.py  # http://localhost:5000

FAQ

Questions fréquentes

Tout ce qu'il faut savoir avant de déployer ton instance.

MaltaiAI est un workspace IA open source que tu héberges toi-même. Il réunit le chat multi-providers, des agents capables d'utiliser des outils (web, fichiers, code, terminal), une mémoire vectorielle et une console d'administration, dans une seule interface web responsive.

Tout endpoint compatible OpenAI : OpenAI, OpenRouter, ainsi qu'Ollama, vLLM ou llama.cpp en local. Tu peux configurer plusieurs providers et basculer de l'un à l'autre selon le besoin.

Oui. Maltai tourne sur ton serveur (Docker, Coolify, Linux, macOS ou Windows) et stocke ses données localement. Tu gardes le contrôle de tes conversations, de tes clés API et de tes fichiers.

Le logiciel est open source et gratuit. Les seuls coûts éventuels sont ceux des providers d'IA payants que tu choisis de brancher (OpenAI, OpenRouter…). Avec Ollama en local, tu peux fonctionner sans coût d'API. L'instance hébergée maltai.fr propose des plans Premium à partir de 9,99€/mois.
